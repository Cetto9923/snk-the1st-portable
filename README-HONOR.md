# 荣耀平板 GT Pro 安装与测试说明

当前社区版本为 `1.0.3`，安装步骤、游戏数据目录及按键操作见[安装与使用指南](docs/release/安装与使用.md)。

荣耀平板 GT Pro（HONOR ROD2-W69 / SM8635 / Adreno 735）使用高通平板分档，底座模式目标为 30 帧，采用原游戏底座渲染档位。显示刷新率与真实游戏帧率分别测量。

本版高通设备分档和厂商条件通过组件回归。荣耀平板的本版安装与真实游戏回归等待 USB 重新连接，发布页记录实际验证范围。

公开附件提供应用、自有界面资源、第三方许可证和校验文件。游戏数据由使用者自行准备，请阅读[版权与免责声明](docs/release/版权与免责说明.md)。
