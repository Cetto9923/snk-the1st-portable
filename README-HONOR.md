# 荣耀平板 GT Pro 安装与测试说明

当前社区版本为 `1.0.6`，安装步骤、游戏数据目录及按键操作见[安装与使用指南](docs/release/安装与使用.md)。

荣耀平板 GT Pro（HONOR ROD2-W69 / SM8635 / Adreno 735）使用高通平板分档，底座模式目标为 30 帧，采用原游戏底座渲染档位。显示刷新率与真实游戏帧率分别测量。

荣耀平板已验证预览运行层的自动横屏、标题及当前存档载入。完整流程、全场景帧率及其他机型的表现以发布页记录的实际验证范围为准。
