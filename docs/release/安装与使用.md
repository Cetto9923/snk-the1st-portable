# 空轨原生兼容运行程序 1.0.1-preview

这是面向社区测试的 Android ARM64 预览版。应用运行用户自行提供的《空之轨迹 the 1st》游戏数据，图形通过 NVN → Vulkan 兼容层呈现。

## 安装

1. 安装 `snk-the1st-1.0.1-preview-arm64.apk`。已装旧版的设备可以尝试覆盖安装，包名为 `org.snk.the1st.gamewindow`。遇到签名冲突时，先备份存档并确认旧版来源。
2. 准备自己合法取得并提取的 v1.0.7 数据，保持以下结构。游戏本体与更新必须完整合并，NSO、RomFS 和转换后的着色器需要来自同一版本。

```text
SNK/
  main.nso
  sdk.nso
  subsdk0.nso
  rtld.nso
  romfs/
  shaders/
```

3. 把 `SNK` 文件夹放到内部存储或存储卡的根目录，也可放在 `Games/SNK`。原始压缩包需要先解压，应用直接读取文件夹。
4. 打开应用。需要权限时点击“授予文件访问权限”，允许后返回应用，再点击“重新检查游戏数据”。使用应用专属目录时也可放到 `Android/data/org.snk.the1st.gamewindow/files/SNK`。

完整资源预期包含 72,360 个 RomFS 文件和 6,611 个 `.xgs` 着色器，其中覆盖 6,584 个原始 asset 着色器阶段。这些数量用于识别旧数据，内容正确性仍需通过提取清单与哈希核对。旧发布包中仅有数百个着色器的数据需要重新补齐。

APK 与本社区应用包均提供 SHA-256 校验文件。下载后可使用校验工具核对完整性。

## 操作

- 触屏上的 `PAD` 轻点可显示或隐藏虚拟手柄，长按进入按键布局编辑。
- 点击 `PAD` 旁的菜单按钮，可选择“编辑按键布局”或“显示手柄 / 隐藏手柄”。
- 编辑时拖动按键调整位置，点选后调整大小，也可调整透明度。点击“完成”保存，点击“恢复默认”重置布局。
- 实体手柄会自动识别。RG477M 使用自身按键与摇杆，虚拟手柄可按需打开。
- 游戏进度通过原游戏的存档功能保存。本版功能菜单提供按键布局与显示设置，金手指功能计划后续加入。

## 设备与测试范围

- RG477M 使用手持档位，目标内部渲染规格为 1280×720，帧率目标为 30。
- 天玑机型采用 720p / 30 帧保守配置，Vulkan 能力以运行时设备查询结果决定。其他天玑设备仍需逐机验证。
- 荣耀平板沿用已有兼容路径，当前帧率目标统一为 30。本版整理期间暂停了荣耀真机测试。
- 帧率目标是调度与限帧设置，实际帧率取决于场景和驱动。当前实测范围与已知问题以发布页记录为准。

应用会在自己的文件目录产生运行日志、管线缓存、按键布局和游戏存档。升级、移动资源或更换测试包前，请备份自己的游戏存档。
