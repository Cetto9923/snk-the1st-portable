# 空轨原生兼容运行程序 1.0.2-preview 安装与使用指南

这是面向社区测试的 Android ARM64 预览版。应用运行用户自行提取的《空之轨迹 the 1st》游戏数据，图形通过 NVN → Vulkan 兼容层呈现。

## 一、 安装步骤

1. 下载并安装 `snk-the1st-1.0.2-preview-arm64.apk`（包名为 `org.snk.the1st.gamewindow`）。若已有旧版，建议先备份存档后再进行覆盖升级。
2. 准备 **v1.0.7** 游戏数据（获取方式：抖音搜索 ID：`Cetto` 进入主页加交流群，群公告已置顶网盘一键下载链接），解压后保持以下目录结构：

```text
SNK/
  main.nso
  sdk.nso
  subsdk0.nso
  rtld.nso
  romfs/
  shaders/
```

3. 将 `SNK` 文件夹放置在手机/设备的**内部存储根目录**（即 `/sdcard/SNK`），或放置在 `Games/SNK`。如果为压缩包需先完整解压。
4. 打开应用。首次打开提示需要权限时，请点击“授予文件访问权限”，允许后返回应用，再点击“重新检查游戏数据”。（亦支持放入应用专属目录 `Android/data/org.snk.the1st.gamewindow/files/SNK`）。

下载完成后，推荐使用随发布的 `SHA256SUMS.txt` 校验工具核对 APK 完整性。

## 三、 操作与控制

- **虚拟触屏手柄**：
  - 点击屏幕上的 `PAD` 按钮可快速显示或隐藏虚拟按键；
  - 长按 `PAD` 按钮或点击菜单中的“编辑按键布局”，可自由拖拽调整按键位置、大小及透明度；
  - 调整完毕点击“完成”保存，亦可随时“恢复默认”。
- **物理手柄支持**：
  - 支持蓝牙手柄、Type-C 有线手柄及掌机原生键位，即插即玩，自动识别按键映射。
- **存档机制**：
  - 游戏进度完全通过游戏原生的存档功能保存，与原版游戏机制一致。

---

## 四、 设备适配与已知问题

- **渲染档位与帧率策略**：
  - 全部设备默认目标帧率设置为 30 FPS。
  - RG477M 等设备自动适配专属档位，采用原游戏 800×450 内部 3D 渲染与底座绘制路径，以平衡发热与性能。
  - 高通/天玑等高端设备将根据 Vulkan 能力动态适配渲染档位。
- **已知限制**：
  - 目前在复杂城镇场景、首次进图或新着色器管线加载时，偶发存在短暂掉帧或卡顿，尚未达到全场景绝对稳定 30 FPS，后续版本将持续优化。
  - 桌面图标采用项目自有的几何图案，游戏内标题画面由用户导入的数据正常呈现。
