# 空之轨迹 the 1st 1.0.6 安装说明

1. **放数据**。解压自行准备的 v1.0.7 游戏数据，将整个 `SNK` 文件夹放到设备“内部存储”的第一层，与 `Download`、`DCIM` 同层。确认路径为 `内部存储/SNK/main.nso`，文件夹内有 `main.nso`、`sdk.nso`、`subsdk0.nso`、`rtld.nso`、`romfs` 和 `shaders`，避免多套一层文件夹。
2. **安装应用**。点击 `snk-the1st-1.0.6-arm64.apk` 安装，按系统提示允许安装。旧版用户先备份存档，再覆盖升级。
3. **授权并开始**。打开应用，点击“授予文件访问权限”，允许本应用管理所有文件，返回后点击“重新检查游戏数据”。首次启动保持应用在前台，等待资源准备完成后开始游戏。

应用自动横屏，支持左右横握。点击 `PAD` 显示或隐藏触控按键，也可使用手柄。进度通过游戏内存档保存。导入 DLC 后，在游戏内 `Item（道具）→ DLC` 中选择“使用”领取。

游戏数据由用户自行提供。版权与免责事项见随包《版权与免责说明》。
